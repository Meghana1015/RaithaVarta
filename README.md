# Raitha Varta – GenAI Powered Smart Agriculture Advisor

Raitha Varta is a multilingual Android application developed to provide farmers with short, actionable, and scientifically verified agricultural guidance through swipeable flash-card tips.

The application transforms lengthy crop advisories into simple daily farming recommendations that are easy to understand and use in real-world farming conditions.

---

## Features

- Multi-language support
- Swipeable farming flash cards
- Offline Room Database support
- Crop-wise filtering
- High-contrast farmer-friendly UI
- Welcome and language selection screens
- Agriculture awareness tips
- Success story cards
- AI-ready architecture

---

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Room Database
- Firebase
- MVVM Architecture
- Material 3
- Coroutines
- Generative AI (GenAI)

---

## Supported Languages

- Kannada
- Hindi
- Telugu
- Tamil
- English

---

## Project Objective

The objective of Raitha Varta is to simplify agricultural knowledge and improve digital accessibility for farmers by delivering scientifically verified farming recommendations in regional languages.
